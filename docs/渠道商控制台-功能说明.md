# 渠道商控制台 · 功能说明

> 适用对象：渠道商（Distributor）与总部（HQ）工作区用户
> 对应实现：`ui/app.js`（控制台壳层/导航/业务模块）、`ui/operator.js` + `ui/operator-frame.html`（专业作业台）
> 更新日期：2026-10-29

---

## 一、整体定位

`Distributor sells; HQ delivers.` —— 渠道商负责连接客户、推进商机；总部负责专业交付。

所有业务数据按**当前租户（tenant）**隔离。渠道商只能看到自己租户范围内的客户、需求与项目。

## 三、模块详解

### 3.1 工作台 —— 生意面总览

**定位**：渠道商每日进入的第一屏，回答「今天该跟什么、哪些客户要推进」。

**数据来源**：当前租户下的 `需求 / 项目 / 客户`（`GET /requests`、`/projects`、`/clients`）。

**包含内容**：

- **KPI 卡片**：待补充资料、待总部确认、进行中项目、客户总数
  - 待补充资料 = `clarification_required`
  - 待总部确认 = `submitted / intake_review / scoping / scope_pending_approval`
  - 进行中项目 = `in_execution / qa / rework / blocked / changes_requested`
- **待处理需求**：按上述状态分组列出
- **最近项目**：按更新时间取最近 8 个（项目 / 客户 / 状态 / 服务阶段 / 更新）
- 有**写权限（writer）**的账号才显示「新建客户」「提交需求」按钮

**一句话**：管客户、管项目进度、看待办——经营视图。

### 3.2 专业作业台 —— 交付面执行台

**定位**：进入某个**已授权项目**，做 GEO 内容增长优化操作的地方。按「项目 + 资源（产品 / 站点）」双重隔离。

**进入的前置条件**（任一不满足即显示空状态）：

1. `GET /growth/workspace` 返回的项目中，仅保留 `capabilities.operate` 为真的项目；
2. 该项目下还需至少有一个授予你 `operate` 的资源（产品 / 站点）。

空状态文案：

- 无项目：`尚无已授权项目。请联系管理员分配项目及作业权限。`
- 有项目但无资源：`该项目尚无授予您的专业作业资源，请联系总部配置具体产品与站点权限。`

**子模块（15 个）**：
`概览 · 产品 · 用户画像 · 场景 · 问句 · 聚类 · 简报 · 引用 · 趋势 · 实体 · 差距 · 关键词 · SEO · 提示词 · 手册`

**操作特性**：

- 顶栏可切换**产品**与**站点**，scope 自动携带 `tenant_id` + `workspace_site_id`；
- 所有写操作走 **If-Match 版本校验 + 幂等键**，保存后刷新对象版本，防并发覆盖；
- 问句 / 关键词支持**分页与 CSV 导出**；
- 顶部边界提示：原生作业流程；自动模型与实时外采未开放；引用检查属传统记录，不替代质量复核后的测量。

**一句话**：进去具体项目做 GEO 优化执行——交付视图。

### 3.3 增长证据与交付 —— 看结果

**定位**：客户 / 项目维度的 **GEO 效果证据**模块。从客户 / 项目看测量与交付结果。

**与专业作业台的区别**：它是「看结果」，作业台是「做执行」；两者互补，不重叠。

### 3.4 我的线索 / 我的客户 / 需求与项目

- **我的线索**：渠道商自己的线索池
- **我的客户**：客户列表 + 新建客户（writer 可建）+ 客户详情（档案 / 关联需求 / 项目 / 跳转 GEO 效果）
- **需求与项目**：需求受理与项目交付进度

### 3.5 功能说明 —— 帮助页

**定位**：即本页的内嵌版本（`#/help`），随产品上线，方便用户随时查阅各模块用途与进入条件。

## 四、模块间流转

```
线索 →(建客户)→ 需求 →(总部确认/审批)→ 项目（进行中）
     → 专业作业台（执行 GEO 优化）→ 增长证据与交付（看效果）
```

## 五、常见问题

### Q1：为什么我的专业作业台是空的？

渠道商管理员默认是「客户与项目管理」身份，**未必被授到具体项目的 `operate` 能力**。所以会出现：工作台能看（管客户 / 项目），专业作业台空着（还没被授权进项目实操）——**这是设计如此，不是故障**。

解决：由总部 / 管理员在对应项目上给你的账号分配 **operate（作业）能力**，重新登录后即可在专业作业台看到该项目。

### Q2：工作台和专业作业台到底有什么区别？

- **工作台** = 生意面总览：管客户、项目、线索的进度与待办（"今天有哪些事要跟进"）。
- **专业作业台** = 交付面执行台：进去某个已授权项目里真正做 GEO 优化操作（品牌 / 站点 / 问句 / 关键词 / 监测 / 优化）。

一个是「管生意」，一个是「做交付」。

### Q3：为什么一进后台是工作台，而不是增长证据？

因为工作台是业务中枢（home）。导航已调整为「业务中枢在前、GEO 交付/执行在后」，默认落地也统一为工作台。
