# ADR-032：终端客户身份与结果发布边界

日期2026-10-19；状态：本机实施与隔离验收通过，未对外部署。依据用户本轮明确授权与Notion Client Workspace P0；规划/审计链见 CUSTOMER-WORKSPACE-REVIEW-20261019.md。

## 决策
1. CLIENT_VIEWER保留渠道租户只读语义。新增END_CUSTOMER，通过既有凭据注册表绑定tenant和client，独立稳定凭据actor；不引入用户/密码库或第二认证平台。现阶段为企业访问码，尚无自助注册、密码找回、团队管理；未来WordPress账号映射须沿用同一服务端绑定与授权。
2. 通用authenticate默认拒绝END_CUSTOMER，新客户API显式允许且逐级检查客户/项目。独立客户Cookie与窄BFF重验凭据、绑定、客户启用状态，不让浏览器参数决定客户身份。
3. 报告client-safe不是客户发布。client_publications承载HQ的明确审查与发布，复用现有QA检查，绑定报告/测量原始内容指纹；客户消费核验快照。撤回和源变更使许可失效，发布过滤先于比较。历史无关联证据不自动移交终端客户。
4. client_reviews只承载资料请求、内容确认、报告反馈与作者处理。状态持久化、版本/幂等与事务防并发，不映射为核心Action或法律/商业项目验收；不覆盖批准范围，不推进交付。
5. 采集器、核心测量、归因与delivery计算源文件保持冻结；新增的是边界授权与业务读取/协作投影，非第二套增长系统。演示独立库只读且仅单虚拟客户可见。

## 结果与限制
用户可从标准官网客户入口进入，看到自己的服务、结果、依据和待办；服务团队能发布/撤回与处理客户意见。没有发布的数据明确标明，单次观察不充当趋势。首期不扩展合同、付款、消息通知、附件或客户成员权限。生产账号交付、HTTPS与既有生产门禁仍需另行验证。
