# 海外 GEO 分销系统
## HQ Technical Delivery Architecture V0.1

**状态：IMPLEMENTATION BASELINE**

## 1. Architecture

```text
                     Distributor Portal
                            │
                     Service Request
                            │
                            ▼
                  ┌─────────────────────┐
                  │  Intake / Scoping   │
                  └──────────┬──────────┘
                             │
                       Technical Scope
                             │
                             ▼
                  ┌─────────────────────┐
                  │       Project       │
                  └──────────┬──────────┘
                             │
                     ┌───────┴────────┐
                     ▼                ▼
               Work Item A       Work Item B ...
                     │
                     ▼
              ┌───────────────┐
              │   GEO Core    │
              │ Observation   │
              │ Measurement   │
              │ Evidence      │
              │ Diagnosis     │
              └───────┬───────┘
                      │
              ┌───────┴────────┐
              ▼                ▼
        open-geo Adapter   GeoLook Adapter
        Measurement        Action/Verification
              │                │
              └───────┬────────┘
                      ▼
             Intervention / ReMeasurement
                      │
                      ▼
                  Technical QA
                      │
                      ▼
                Delivery Package
                      │
                      ▼
                Distributor Portal
```

## 2. Core Modules

### M1 Intake
职责：接收 Service Request，判断完整性。

输出：
- ACCEPTED
- CLARIFICATION_REQUIRED
- REJECTED

### M2 Scoping
HQ 将商业需求转为 Technical Scope。

### M3 Project Orchestrator
管理 Project 与 Work Item，不承载 GEO 算法。

### M4 GEO Core
Canonical pipeline：

```text
RawResponse
→ Observation
→ Measurement
→ Evidence
→ Diagnosis
→ InterventionHypothesis
→ Experiment
→ ReMeasurement
→ ObservedEffect
→ Interpretation
```

### M5 Measurement Adapter
第一适配器：open-geo。

### M6 Action / Verification Adapter
第一参考：GeoLook。

### M7 Delivery
生成：
- HQ Technical Report
- Client/Distributor Report
- Delivery Result

### M8 QA
验证：
- completeness
- evidence integrity
- report consistency
- scope compliance
- client-safe output

## 3. State Machines

### Request
```text
DRAFT
→ SUBMITTED
→ INTAKE_REVIEW
→ CLARIFICATION_REQUIRED
→ SCOPING
→ SCOPE_PENDING_APPROVAL
→ APPROVED
```

### Project
```text
APPROVED
→ IN_EXECUTION
→ QA
→ DELIVERED
→ ACCEPTED
```

异常：
```text
BLOCKED
REWORK
CHANGES_REQUESTED
CANCELLED
```

## 6. Adapter Boundaries

### open-geo
输入：
- Query Set
- Engine
- Sampling Context

输出：
- QueryCapture
- raw answer
- sources/citations
- screenshot/reference
- sampling metadata

HQ 转换为 Canonical Observation / Measurement。

### GeoLook
输入：
- relevant evidence / diagnosis context

输出：
- audit/action suggestions
- verification concepts

HQ 决定是否采纳。

## 7. Data Ownership

HQ owns：
- technical truth
- evidence
- methodology
- measurement
- diagnosis
- technical reports

Portal owns：
- lead
- client
- commercial request
- commercial status
- distributor relationship

## 8. Security / Isolation Baseline

MVP 至少保证：

1. Distributor A 不可读取 Distributor B 数据。
2. Distributor 只能访问自己被授权的 Client / Project。
3. Client-safe report 与 HQ Technical Report 分离。
4. RawResponse 默认不进入 Distributor API。
5. HQ internal notes 不进入 Portal。

具体 RBAC 实现留到实现阶段，不提前设计完整 IAM 平台。

## 9. Non-goals

本版本不实现：

- CRM
- billing engine
- commission engine
- revenue attribution
- distributor technical console
- arbitrary workflow builder
- full event bus
- multi-region infrastructure
