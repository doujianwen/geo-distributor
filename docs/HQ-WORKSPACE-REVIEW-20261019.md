## 初审：目标与代码事实

总部主线为：线索分配→需求受理/拟定范围→管理批准→项目交付→技术报告→明确向客户发布→处理客户反馈。

现有原生 JS/FastAPI/SQLite 是 geo-distributor 服务，官网只承接入口。现有总部与渠道共用四个导航，工作台仅统计登录租户；需求列表跨租户但客户/项目仍只查当前租户，造成总部看得见需求却找不到对应客户/项目。线索页可选择已注册渠道，但缺少跨租户统一任务队列、客户结果发布与反馈总览。已有真实审批、发布指纹检查、客户协作及服务端角色守卫，必须复用。

## 拟定页面与边界

| 页面 | 目标和操作 |
|---|---|
| 总部工作台 | 明确全渠道或所选渠道范围，待分配、待拟范围、待批准、受阻、待处理反馈、发布异常独立计数；逐项进入对象 |
| 线索分配 | 可搜索/筛选已分配与待分配线索，注册渠道下拉，明确联系人与需求，分配后原对象关联，防重复建客户 |
| 需求受理 | 搜索、状态与渠道筛选；拟范围/补充/拒绝/批准继续既有 revision 保护；技术角色不能批准 |
| 项目交付 | 跨渠道客户名称、阶段和项目状态、阻塞、下一步；进入既有项目/GEO/报告；总部操作明确对象与阶段 |
| 客户与渠道 | 客户目录与只读渠道业务汇总，不输出密钥/员工凭证；切换范围后重置详情上下文，跨页筛选保留 |
| 结果与反馈 | 已有报告及当前发布状态、失效原因；客户反馈 pending 与已答待处理分开；进入项目办理，无新第二套发布/协作 |
| 操作记录 | 从已持久化需求/线索/发布/协作/总部交付事件读取，显示来源、时间、结果、角色；明确是业务处理记录，非完整安全日志 |

不建新的财务/佣金/团队/密码/通知体系，不自动补发线索或执行外部测量；不提供清库、凭据编辑、批量批准或默认报价。总部运营采用现有 HQ_TECHNICAL 能力，管理采用 HQ_MANAGEMENT；这是能力角色，尚非逐员工审计系统。

列表每页20条，前端完整搜索/状态筛选；全量聚合在内部 HQ 专用读取接口中执行，不把渠道全量数据下发渠道身份。所有跨页链接携带资源渠道上下文，旧链接兼容；需求按自身归属核验。错误/未知/空分别表达，401回登录，异步旧响应不可覆盖新路由。

## 红队挑战与定向补充（第一轮）

| ID | 质疑/缺陷 | 定向补充及验收门槛 |
|---|---|---|
| H01 P1 | 总部默认范围只在总部租户，空统计制造假全局 | HQ独立只读聚合，全渠道默认；范围始终可见；注册渠道及已有对象渠道共同形成目录，不透露凭据 |
| H02 P0 | 浏览器带tenant就能获得总部全量数据 | /hq 逐请求 require_hq；渠道/只读/终端客户全拒绝，BFF只增加hq前缀，原防护保留 |
| H03 P1 | 跨渠道跳详情丢归属或同名客户混淆 | 复合tenant+client索引及所有深链上下文；详情独立按资源核验；客户/项目/报告不信任列表显示名 |
| H04 P1 | 客户发布记录存在但指纹已变，统计还称已发布 | 复用 publication_valid/currently_visible 校验，不把历史status当可见；失效单列；报告无发布记录为未发布 |
| H05 P1 | 客户已提交反馈仍被统计为客户待办 | pending为待客户；submitted/confirmed/changes_requested为待服务团队；closed/withdrawn不计待办 |
| H06 P1 | 双击分配或并发创建产生孤儿客户 | 线索分配的读/校验/建客户/写线索在同一SQLite事务，稳定客户ID及重试指纹；旧已分配返回冲突或同一结果 |
| H07 P1 | 多次阶段点击跳两阶段、旧页操作错阶段 | 交付操作采用明确expected_updated_at和持久化幂等键，原子状态变更及业务历史；只允许有效项目状态；不把完成阶段当验收 |
| H08 P1 | 报告生成成功被称项目交付/客户已看到 | 保留项目、报告生成、客户发布三种事实；不自动改变项目验收或发布客户；复用原报告生成算法与scope幂等 |
| H09 P2 | 审计表暴露PII、密钥或被称完整安全日志 | 只汇总业务事件白名单，不含完整联系人邮件/原始payload/凭证/系统配置；单列记录覆盖限制 |
| H10 P1 | 演示使用真实总部凭据或可写全库 | 独立进程只读总部演示随机角色密钥、独立cookie，DEMO_ONLY屏障继续拒绝所有业务写；真实写入在临时独立库 |
| H11 P2 | 审批范围编辑后误批准旧范围，离开丢输入 | 范围编辑禁批准，dirty guard覆盖总部表单；409保留输入要求刷新，成功才清除 |
| H12 P2 | 聚合读取失败被吞掉成零待办 | 聚合依赖失败返回明确错误，无不完整总计；页面可重试与保留导航；安全日志不冒充全量 |
