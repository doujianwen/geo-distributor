| 代码 | 归因 | 判定证据要求 |

| **A** | Intervention（内容干预） | 变化的 query 与已部署文章主题对齐；对照组同期无同向变化；变化出现在收录后窗口（7–14d） |

| **E** | Unknown（未知） | 证据不足以排除任一项；默认归此类直至补充测量 |
