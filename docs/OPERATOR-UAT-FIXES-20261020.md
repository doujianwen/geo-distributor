## 定向对抗性复核

本轮由主实施者执行，不冒称新增独立审计：

- 导出范围在服务端重新校验项目、客户、所选站点和 operate 能力；只读/撤权账号不能通过复制附件链接导出。
- 客户附件路径拒绝 tenant_id、重复范围参数；不接受浏览器指定另一个客户。非授权对象/原始观察不在导出路由内。
- CSV 采用明确字段清单，不输出内部授权、版本哈希或原始回答字段；文本以 `= + - @` 等开头时转为字面值，防电子表格公式执行。
- 全部导出分页位于同一个只读事务快照，无 GET 写入副作用；超过数量或体积限制明确报错。
- 项目快捷入口来自后端授权结果，不硬编码向其他客户披露两个总部自营项目名称。
- 现有监测配置同步走专业命令边界、资源版本与持久化幂等，按产品处理，仅改启用任务的目标配置；暂停任务及历史 citations 不被冒名替换。
- 对旧 JSON 引擎列表单独补测，避免仅替换逗号文本而漏掉 14 条旧格式任务。原库备份为 `data/historical-adoption-20261020/core-before-copilot.db`。
