## 二、V0.2 必改项

### 1. 新增 Compatibility Layer（核心战场）

A1.6 的真实任务是 Compatibility Test，不是业务开发。

```
geo_distributor/
└── compatibility/        ← 新增
    ├── __init__.py
    ├── base.py           # 映射基类 + Observation 统一契约
    ├── observation.py    # geo-collector ↔ 商业模型 映射
    ├── citation.py       # Citation 字段映射
    ├── measurement.py    # Measurement 字段映射（待定义）
    └── diagnosis.py      # Diagnosis 字段映射（待定义）
```

**关键原则：Elmo 与 GeoCollector 输出同一个 `Observation` 对象。**

```
GeoCollectorAdapter  →  geo-collector Observation  →  Compatibility Mapper  →  Platform Observation
ElmoAdapter          →  Elmo Evaluation/Citation    →  Compatibility Mapper  →  Platform Observation
```

两者在 `compatibility/` 层汇合，下游业务代码只看到 `Platform Observation`。

---

### 2. Observation 成为核心模型

当前 `models/` 缺少 Observation。补全核心链路：

```
Prompt → Observation → Citation → Measurement → Diagnosis
```

新增模型：

```python
@dataclass
class Prompt:
    prompt_id: int
    category: str
    intent: str
    location: str
    text: str
    source: str = ""
    family_id: str = ""
    variant: str = "original"
    tier: str = ""

@dataclass
class Observation:
    observation_id: str
    prompt_id: int
    engine: str
    timestamp: str
    prompt_text: str
    answer_raw: str
    answer_clean: str
    answer_char_count: int
    brand: str
    brand_mentioned: bool
    brand_status: str
    first_mention_position: Optional[int]
    recommendation_level: int
    recommendation_rank: Optional[int]
    recommendation_evidence: str
    competitors: List[dict]
    citations: List[dict]
    citations_status: str
    status: str
    metadata: dict = field(default_factory=dict)

@dataclass
class Citation:
    observation_id: str
    url: str
    domain: str
    title: str
    citation_index: int
    citation_type: str
    anchor_text: str
    context: str
```

### 3. BaseAdapter 输出统一为 Observation

V0.1 的 `run_collection() -> Run` 让 GeoCollector 成为隐式唯一数据源。
V0.2 改为：

```python
class BaseAdapter(ABC):
    @abstractmethod
    async def collect_prompt(self, prompt: Prompt) -> Observation:
        """收集单个 prompt，返回统一格式的 Observation。"""
        ...

    @abstractmethod
    async def health_check(self) -> bool:
        ...

    # run_collection 改为高层编排，不属于 Adapter 契约
```

这样：
- Elmo 未来输出 Observation，不输出 Run
- GeoCollector 输出 Observation，不绑定唯一数据源地位

### 统一契约：Platform Observation

```python
@dataclass
class PlatformObservation:
    """所有 Adapter 输出的统一格式。"""
    observation_id: str
    prompt_id: int
    engine: str
    timestamp: str
    prompt_text: str
    answer_raw: str
    answer_clean: str
    answer_char_count: int
    extraction_method: str
    validation_status: str
    brand: str
    brand_mentioned: bool
    brand_status: str
    first_mention_position: Optional[int]
    recommendation_level: int
    recommendation_rank: Optional[int]
    recommendation_evidence: str
    competitors: List[dict]
    citations: List[dict]
    citations_status: str
    status: str
    raw_metadata: dict = field(default_factory=dict)  # 保留原始数据供调试
```

### geo-collector → PlatformObservation 映射

```python
# compatibility/observation.py
def map_geo_collector_observation(obs: StorageObservation) -> PlatformObservation:
    """将 geo-collector 的 Observation 映射为 PlatformObservation。"""
    return PlatformObservation(
        observation_id=obs.observation_id,
        prompt_id=obs.prompt_id,
        engine=obs.engine,
        timestamp=obs.timestamp,
        prompt_text=obs.prompt,
        answer_raw=obs.answer_raw,
        answer_clean=obs.answer_clean,
        answer_char_count=obs.answer_char_count,
        extraction_method=obs.answer_extraction_method,
        validation_status=obs.answer_validation_status,
        brand=obs.brand,
        brand_mentioned=obs.brand_mentioned,
        brand_status=obs.brand_status,
        first_mention_position=obs.first_mention_position,
        recommendation_level=obs.recommendation_level,
        recommendation_rank=obs.recommendation_rank,
        recommendation_evidence=obs.recommendation_evidence,
        competitors=obs.competitors,
        citations=obs.citations,
        citations_status=obs.citations_status,
        status=obs.status,
    )
```
