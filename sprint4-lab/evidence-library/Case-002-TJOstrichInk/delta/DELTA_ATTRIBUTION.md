## 归因分类（A–E）

若 BookConv 在任一 Checkpoint 出现可观测变化（Mention/Citation/Recommendation/Coverage/Visibility Delta ≠ 0），必须回答变化来自：

| 代码 | 归因 | 判定证据要求 |
|------|------|--------------|
| **A** | Intervention（内容干预） | 变化的 query 与已部署文章主题对齐；对照组同期无同向变化；变化出现在收录后窗口（7–14d） |
| **B** | Bing Refresh（引擎刷新） | 全站/全网普遍性波动；对照组同期同向变化；与内容部署无时间相关性 |
| **C** | Indexing（收录/索引变化） | 新页面进入索引（URL 收录 + 参与排名）；可用 GSC / Bing Webmaster 收录日志佐证 |
| **D** | Random Variation（随机波动） | 变化幅度 < 测量噪声阈值；历史基线方差内；无系统性方向 |
| **E** | Unknown（未知） | 证据不足以排除任一项；默认归此类直至补充测量 |

## 归因决策树（Evidence First）

```
BookConv 出现 Delta?
├─ 否 → 记录「无变化」，无需归因
└─ 是 → 同步检查 TJOstrichInk（对照组）同期：
        ├─ 对照组同向变化 → 偏向 B / C / D（非 Intervention）
        └─ 对照组平稳     → 检查变化 query 是否对齐已部署文章：
                            ├─ 对齐 + 收录窗口吻合 → 偏向 A（但需排除 C）
                            └─ 不对齐           → E（Unknown）
```

## 各归因的证据采集清单

- **A (Intervention)**：① 变化 query 列表 ∩ 已部署文章覆盖 query；② 文章收录时间线（GSC/Bing WM）；③ 对照组无同向；④ 时间窗（部署→收录→重测）合理
- **B (Bing Refresh)**：① 全网/行业普遍波动信号；② 对照组同步；③ 与部署日期无相关
- **C (Indexing)**：① 新 URL 收录证明；② 该 URL 开始产生 impression/citation 的时间点
- **D (Random)**：① Δ 小于基线标准差；② 无方向性；③ 历史回测稳定
- **E (Unknown)**：① 上述任一证据缺失 → 标 Unknown，禁止降级为 A
